# Kingsxchange

A crypto exchange website concept built for Nigerian users, focused on making crypto trading feel accessible and localized.

## Features

- **Live Crypto Rates Table** — displays real-time pricing for major cryptocurrencies
- **NGN-to-Crypto Conversion Widget** — lets users quickly convert between Nigerian Naira and crypto values
- **Crypto Ticker** — scrolling price ticker for at-a-glance market updates
- **Responsive Design** — built with CSS Grid, Flexbox, and media queries for a consistent experience across mobile, tablet, and desktop

## Tech Stack

- HTML
- CSS
- JavaScript

## Design

Blue-themed UI tailored for a Nigerian crypto audience, with layout designed to keep rate information front and center.
